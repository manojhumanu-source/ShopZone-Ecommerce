# ShopZone – E-Commerce Web Application

A responsive e-commerce web application built using React and JavaScript. ShopZone provides a shopping experience with product browsing, search, filtering, cart management, wishlist, authentication, checkout, and order history.

## Features

- **Product Listing:** Fetch and display products using the DummyJSON API.
- **Search:** Search products by name.
- **Category Filter:** Filter products by category.
- **Sorting:** Sort products by price, rating, and name.
- **Pagination:** Display products across multiple pages.
- **Product Details:** View individual product information.
- **Shopping Cart:** Add, remove, and update product quantities.
- **Wishlist:** Save and manage favourite products.
- **User Authentication:** Register, login, and logout.
- **Protected Routes:** Restrict access to selected pages.
- **Checkout:** Enter delivery details and select a payment method.
- **Order Management:** View order history and cancel orders.
- **Local Storage:** Persist cart, wishlist, user and order data.

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/manojhumanu-source/ShopZone-Ecommerce.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ShopZone-Ecommerce
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## API

Product data is fetched from:

https://dummyjson.com/products?limit=0
